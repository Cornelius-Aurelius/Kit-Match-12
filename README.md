# Kit Match 12 — Matchday Academy

An original football visual recognition game created, designed and developed by **Cornelius Aurelius**. Official creator: https://corneliusaurelius.com/

Live website: https://cornelius-aurelius.github.io/Kit-Match-12/

## How to play
You are Number 12. Match the *full* kit worn by a teammate, ignoring the shirt number. Look beyond colour to distinctive shirt patterns, shorts details, socks, sleeve markings and badge shapes. Select on-screen cards or press keys 1-8.

## Modes
- Campaign: 30 stages, three lives and progression, automatic advancement, high scores.
- Blitz: 90-second points challenge with three lives.
- Practice: no clock or life limit.

H provides a non-spoiler hint; P/Escape pauses. A button cycles Stadium / Sunset / High Contrast themes and audio is opt-in. Progress is stored in the local browser only.

## Educational note
This is not a colour-vision simulation or medical test, and it is not an official kit approval tool. See The FA colour-vision guidance for football. All levels have a unique correct answer and non-colour visual differences.
